# Baseline protocol (written before running the tools)
Tools run with default settings on each case file. For a positive case, a tool "detects the
relationship" only if one finding or output line names objects owned by two different teams
that are involved in the case. Naming only one object does not count. For a clean case, the
same event counts as a false finding. Candidates are produced automatically and then confirmed
manually. Object-level mentions are reported separately and are not detections.
